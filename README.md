# unlibra community

unlibra が公開しているすべてのプロダクトについての、共通の問い合わせ窓口です。
質問、不具合の報告、機能の要望は [Discussions](https://github.com/unlibra/community/discussions) で受け付けています。

## 投稿先

| カテゴリ | 用途 |
| --- | --- |
| [📣 Announcements](https://github.com/unlibra/community/discussions/categories/announcements) | 運営からのお知らせ（投稿は運営のみ） |
| [🙏 Q&A](https://github.com/unlibra/community/discussions/categories/q-a) | 使い方の質問、うまく動かないときの相談 |
| [🐛 Bug reports](https://github.com/unlibra/community/discussions/categories/bug-reports) | 不具合の報告 |
| [💡 Ideas](https://github.com/unlibra/community/discussions/categories/ideas) | 機能の追加・改善の要望 |

どのカテゴリか迷ったら Q&A に投稿してください。

## 投稿の前に

- 同じ内容の投稿がないか、[検索](https://github.com/unlibra/community/discussions) で確認してください。
- 投稿フォームの「対象プロダクト」に、プロダクト名を書いてください。
- 不具合の報告では、再現手順と環境（OS、バージョンなど）があると調査が早くなります。

## ご注意

- 投稿は誰でも閲覧できます。パスワード、個人情報、非公開のデータは書かないでください。
- 返信には時間がかかる場合があります。すべての要望への対応はお約束できません。

---

English is also welcome. This is the shared support hub for all unlibra products. Please post questions, bug reports, and feature requests in [Discussions](https://github.com/unlibra/community/discussions).
