# unlibra community

> **English is also welcome.** This is the shared support hub for all unlibra products. Please report bugs in [Issues](https://github.com/unlibra/community/issues), and post questions and feature requests in [Discussions](https://github.com/unlibra/community/discussions).

[unlibra](https://github.com/unlibra) が公開しているすべてのプロダクトについての、共通の問い合わせ窓口です。
不具合の報告は [Issues](https://github.com/unlibra/community/issues) で、質問、機能の要望、その他の話題は [Discussions](https://github.com/unlibra/community/discussions) で受け付けています。

## 投稿先

| 投稿先 | 用途 |
| --- | --- |
| [🐛 Issues](https://github.com/unlibra/community/issues/new/choose) | 不具合の報告 |
| [🙏 Q&A](https://github.com/unlibra/community/discussions/categories/q-a) | 使い方の質問、うまく動かないときの相談 |
| [💬 General](https://github.com/unlibra/community/discussions/categories/general) | 機能の要望、感想、その他の話題 |
| [📣 Announcements](https://github.com/unlibra/community/discussions/categories/announcements) | 運営からのお知らせ（投稿は運営のみ） |

不具合かどうか分からないときは、Q&A に投稿してください。

## 投稿の前に

- 同じ内容の投稿がないか、[Issues](https://github.com/unlibra/community/issues?q=) と [Discussions](https://github.com/unlibra/community/discussions) を検索してください。
- 特定のプロダクトについての投稿では、フォームの「対象プロダクト」にプロダクト名を書いてください。
- 不具合の報告では、再現手順と環境（OS、バージョンなど）があると調査が早くなります。

## ご注意

- 投稿は誰でも閲覧できます。パスワード、個人情報、非公開のデータは書かないでください。
- 返信には時間がかかる場合があります。すべての要望への対応はお約束できません。
